Chats and peers take shape, identities get a model, and Tor arrives as a wrapper.

## Features

- The chats list and the peers page, rebuilt around how conversations will work
- An identity model, the start of identities that live only on the phone
- A Tor wrapper and a native security channel that checks the app's own signature
- The map moves to the new maplibre package, and the offline download is reorganized

## Changes

- The zstd experiment is removed
- An implementation plan and a code of conduct are written

## Known issues

- Tor does not start reliably yet, so nothing reaches another phone
- Chats and peers show no real conversations yet
