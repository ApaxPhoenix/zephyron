The first beta: Tor runs inside the app, and identities can be created and unlocked.

## Features

- Tor runs inside the app through its C API, with obfs4 bridges set from the network screen
- Sign-up and log-in with identities: a recovery phrase and a passphrase, several identities on one phone
- The groundwork for radios over USB and serial
- A build workflow that builds every platform on GitHub Actions

## Fixes

- The Tor daemon starts on every launch instead of only sometimes

## Known issues

- Messages can't be sent yet
- Tor can take a few minutes to bootstrap on a slow network
- Tor runs only on Android; the other platforms build without it
