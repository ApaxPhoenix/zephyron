Packaged for every platform: GitHub Actions builds, tests and releases Zephyron from what passed.

## Features

- Packages for every platform: Android APKs and an app bundle, an unsigned iOS archive, a macOS disk image, installer package and archives, Windows installers and archives for x64 and ARM64, and Linux `.deb`, `.rpm` and archives for x64 and ARM64, with SHA-256 checksums
- Releases named by `VERSION` and described by notes in `releases/`, made by a workflow of their own once Build passes

## Known issues

- Leaving the app with Back and opening it again can still crash a release build
- Scanning a code with another phone's camera doesn't open Zephyron yet
- The iOS and macOS packages are unsigned
- The Windows installers come with WiX's debug data beside them
- Tor runs only on Android; the other platforms build without it
