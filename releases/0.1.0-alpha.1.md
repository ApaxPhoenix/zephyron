The first alpha: the app's shell on every platform, with the offline map. Nothing talks to anything yet.

## Features

- One Flutter project for Android, iOS, macOS, Linux, Windows and the web
- The network map screen, with an offline map downloaded once and kept on the device
- A first discussion screen, the splash screen and the app's entry point

## Known issues

- There are no identities, no Tor and no messages yet; the discussion screen shows sample content
- The map download talks to Cloudflare R2 directly, not through Tor
- zstd compression over FFI is an experiment and may not stay
