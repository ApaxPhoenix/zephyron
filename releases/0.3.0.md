Messages that reach you: delivered live and to locked phones, announced without saying what they say, and released by GitHub Actions for every platform.

## Features

- A locked phone stays reachable: its address stays online, and what arrives is kept sealed to a key inside the locked store and read at the next unlock
- Notifications through the phone's own notification manager that only say who wrote and how many messages, never what they say; while locked, not even who
- Scan a trustee's code with your phone's camera: the zephyron:// link it holds opens Zephyron with their address filled in
- Long-press the app icon to add a trustee, show your code, lock the vault or start a panic wipe
- Chats, requests and trustees in one tab, with filters for unread, groups, pinned, archived and blocked
- Photos, files, sharing, QR codes and audio and video playback in our own code, with no picker, player or sharing packages
- Packages for every platform, attached here: Android APKs and an app bundle, an unsigned iOS archive, a macOS disk image, installer package and archives, Windows installers and archives for x64 and ARM64, and Linux `.deb`, `.rpm` and archives for x64 and ARM64
- A threat model, `SECURITY.md`, saying what Zephyron protects and what it does not

## Fixes

- Reopening the app after leaving it with Back no longer crashes it: Android kept the process alive, a second Tor started inside it and aborted, and now the Tor already running there is reused
- Scanning a code with another phone's camera opens Zephyron instead of saying the zephyron:// protocol doesn't exist
- Onion addresses carry the checksum Tor expects, SHA3-256 rather than SHA-256, so Tor accepts them and messages go through; addresses saved with the old checksum are corrected at the first unlock
- A phone reopens on the unlock page when it already has an identity, and the identity picker fits narrow screens
- Tor is asked to forget a peer's stale descriptor when they come back online with new introduction points
- The Windows installers no longer carry WiX's debug data beside them

## Changes

- Releases are made by GitHub Actions from what the Build workflow tested, named by `VERSION` and described by these notes

## Known issues

- Tor runs only on Android; the other platforms build without it
- The iOS and macOS packages are unsigned
- Both phones need 0.3.0-beta.1 or later to reach each other, since older versions still dial with the old checksum
- A phone without Zephyron installed still can't open a scanned zephyron:// code
