Tor on iPhone: the iOS app runs Tor inside itself, so an iPhone can reach Android phones and other iPhones.

## Features

- Tor runs inside the iOS app on Tor.framework's own thread, with the same onion service and SOCKS setup as on Android
- obfs4 bridges on iOS, through IPtProxy running inside the app
- A Build test that boots Tor on an iOS simulator, publishes an onion service and reaches it through Tor before every release

## Changes

- The iOS app needs iOS 15 or later, up from 13, as Tor.framework does
- A failed iOS build shows Xcode's own error, not only Flutter's note about signing

## Known issues

- An iPhone is reachable only while Zephyron is open: iOS suspends the app, and Tor with it, soon after it leaves the screen
- Tested on the iOS simulator, not yet on a real iPhone
- Post-quantum sessions still fall back to classical encryption on iOS
- The iOS and macOS packages are unsigned
- Tor isn't on macOS, Windows or Linux yet
